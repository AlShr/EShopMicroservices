| Service | Database / data store |

[src-services-basket-basket-api-appsettings-json] [src-docker-compose-yml] |

| **Ordering API** | **OrderDb on Microsoft SQL Server**. The API uses an `OrderDb` connection string, registers a SQL Server health check, and Docker Compose defines `orderdb` with the Microsoft SQL Server image. [src-services-ordering-ordering-api-appsettings-json] [src-services-ordering-ordering-api-dependencyinjection-cs] [src-docker-compose-yml] |
| **Shopping.Web** | A web client with interfaces for Catalog, Basket, and Ordering services; no directly owned database is evidenced in the retrieved material.
