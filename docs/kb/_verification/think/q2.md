# How does Basket get discounts?

## Answer

Basket gets discounts from the **Discount gRPC service**. Its discount-deduction logic iterates through every cart item and calls `GetDiscountAsync`, passing the item’s `ProductName`. It then subtracts the returned coupon `Amount` from that item’s `Price`. [src-services-basket-basket-api-basket-storebasket-storebasketbaskethandler-cs]

The Discount service looks up a coupon whose `ProductName` matches the request. If none exists, it returns a fallback coupon with an amount of `0`, so the item price remains unchanged. [src-services-discount-discount-grpc-services-discountservice-cs]

The Basket API’s configured Discount endpoint is `https://localhost:5052` locally; in Docker it is overridden to `https://discount.grpc:8081`. [src-services-basket-basket-api-appsettings-json] [src-docker-compose-override-yml]
